# STYLE — accumulated user taste

Read before every `talk-new`; appended to by `talk-revise` when feedback generalizes.
Format: one dated bullet per preference, quoting the feedback that spawned it.

## Slides

- Status/overview slides too: state the trend, don't enumerate the program — e.g. replace a
  "two complementary attacks" list (with per-item citations) by one line "less SUSY ⇒ richer
  landscape ⇒ classification wide open". (2026-07-22: "two complementary attack 파트 지우면
  좋겠어 그냥 less susy more rich 이런 느낌으로 적어줘")

## Script

- Pitch motivation sections to the actual audience, not to formal field theorists: build
  the case from first principles (strong coupling is hard → SUSY as a mathematical tool,
  independent of whether it describes the real world → superconformal symmetry as the
  non-perturbative handle) instead of assuming the problem is self-evidently interesting.
  (2026-07-20: "청중들이 formal field theorist 가 아니라서 그들에게 맞게 하고 싶은데")
- Status/overview frames: convey the trend, don't enumerate the items — e.g. "more SUSY →
  more constrained → better classified", not each construction one by one. (2026-07-20:
  "그냥 많은 supersymmetry -> 쉬움 이런 느낌만 전달할 수 있으면 좋음. 일일히 어떤
  construction이 있는지 말할 필요 없을 듯")
- For non-specialist audiences, prefer simple-but-slightly-imprecise over exact-but-technical
  in the spoken narrative — e.g. present the WGC test as a single-U(1) maximal q/Δ and park
  the convex-hull truth in a backup frame. (2026-07-21: "청자들도 이쪽 분야가 아니기 때문에
  convex hull 언급하지않고 정확하지 않아도 그냥 single U(1)인것처럼 다루는게 좋을 거 같아")
- Introduce technical constructions by what they do, not by their limit/parameter jargon —
  e.g. "the superconformal index counts BPS states, and it obeys an analog of Cardy's
  formula" instead of "take the index in the Cardy-like limit where the angular fugacities
  go to zero". (2026-07-23: "사람들이 index나 fugacity 뭔소린지 모를테니까 BPS를 count하는
  superconformal index에서도 비슷한 cardy formula같은 analogy를 썼을 때...")
